**Connecting neighborhood socioeconomics to community outcomes across three of Chicago's public datasets — entirely through SQL.**

## 🔎 The datasets

| Dataset | What it covers |
| --- | --- |
| 🚨 Chicago Crime Data | Reported incidents of crime across the city |
| 🏘️ Census / Socioeconomic Data | Hardship index, per-capita income, poverty rates by community area |
| 🏫 Chicago Public Schools | School-level performance and safety metrics |

## 📊 What the analysis uncovers

- Which community areas carry the highest hardship index and how that correlates with crime frequency
- School safety and performance patterns across socioeconomically different neighborhoods
- Crime-type breakdowns and location patterns (e.g., school-adjacent incidents)
- Joins across all three datasets to link demographics → schools → crime outcomes

## ▶️ How to run

Open `DB0201EN-PeerAssign-v5 (1).ipynb` in Jupyter, JupyterLab, or Google Colab and run the cells — queries execute via SQL magic against the loaded datasets.

## 🛠️ Tools

`SQL` (joins, aggregation, subqueries) · `Python` · `Pandas` · `Jupyter Notebook`
