# 🏙️ Chicago Data Analysis

A SQL-driven exploratory analysis of Chicago's public datasets, covering crime, census, and public school data.

## Overview
This project uses SQL queries to explore and analyze Chicago's socioeconomic, crime, and public school datasets, uncovering relationships between neighborhood demographics and community outcomes.

## Contents
- `DB0201EN-PeerAssign-v5 (1).ipynb` — Jupyter notebook with SQL-based data analysis and peer assignment

## Tools Used
- Python
- SQL (SQLite / Db2)
- Pandas
- Jupyter Notebook

## How to View
Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab to run the SQL queries and view the analysis.
